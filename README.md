# 运动员体能与功能评估系统 · 零基础安装与运行指南

> 适用环境：Windows 10 / 11，使用系统自带的 PowerShell。
> 你**不需要任何编程基础**，全程只要「复制命令 → 粘贴 → 按回车」。
> 预计用时 15~25 分钟，其中大部分是等待下载。

本系统只做一件事：**体能与功能评估的数据采集、记录与分析**。
界面统一使用「测试与评估」这一术语；内置评分常模为示意性示例值，**非专业常模，请按本队实测替换**。

| 新增「05 分析报告」 | 基于已记录的测试数据、按运动项目生成针对性报告，内含**不足项、原因分析、下一步改善建议**三要素，可导出 Markdown 与 CSV。 |

**旧数据原有的 192 条记录与前 7 列完全不变**，读取时缺列自动补空。升级前建议先复制一份 `data` 文件夹。

## 核心规则速览

### 年龄分档与标准组

按**测试日期当天的实足年龄**自动分档，分组键为「性别|年龄组」：

| 年龄组 | 实足年龄 |
| --- | --- |
| U16 | < 16 |
| U18 | 16 - 17 |
| U20 | 18 - 19 |
| 成年 | 20 - 34 |
| 大师 | >= 35 |

- 建档表单会按当前日期实时显示「适用标准组」；名单中的「标准组」也按当前日期算。
- **历史记录按测试日分组，且为写入时的快照**：之后修改运动员出生日期，已有记录的标准组不会漂移。

### 评分器（按「评分类型」分派）

| 评分类型 | 规则 |
| --- | --- |
| `continuous` | 按「性别\|年龄组」的达标线（60 分）/ 优秀线（100 分）线性换算 0~100 分；四档等级：优秀 >=90、良好 >=75、达标 >=60、待提升 <60 |
| `ordinal` | FMS 7 个动作保留 0~3 原始分；5 个双侧动作取较低侧计入；总分 0~21，<=14 为较高风险 |
| `binary` | 3 项排除性测试「通过 / 阳性」，阳性使对应动作记 0 分 |
| `descriptive` | 身高 / 体重 / BMI 等仅记录不评分 |

- 未配置的组合不评分，得分显示 `—`。
- **FMS 的 0~3 分绝不进入平均体能得分、达标率或 0~100 坐标轴。**
- 0 分或排除性测试阳性会触发红色警示「存在疼痛，建议转介医疗或康复评估」，
  该次总分加注「含疼痛项，结果需谨慎解读」；左右差 >= 1 的动作进入左右不对称清单。
- 得分 / 等级 / FMS总分 / 不对称标记均为**派生量，不落盘**，
  因此在「评分标准」页改动任意一条阈值后，全部历史得分会自动重算。

### 数据契约

- `athletes.csv` 的 8 列依次为：
  `运动员ID, 姓名, 性别, 出生日期, 所属队伍, 专项, 备注, 运动项目`。
  「运动项目」在「01 运动员管理」的新增与修改表单中都是**必填**；「专项」仍是具体小项。
- `tests.csv` 的 14 列依次为：
  `记录ID, 运动员ID, 测试日期, 测试项目, 成绩, 单位, 备注, 测试类别, 评分类型, 侧别, 标准组, 测试时年龄, 疼痛标记, 运动项目`。
- **「运动项目」是写入时快照**：录入时由运动员档案自动带出并随记录一起保存，
  之后修改档案不会改动已有记录；单项录入、批量录入、FMS 录入矩阵与演示数据都遵循同一规则。
- 启动时会自动迁移旧格式：由「专项 / 所属队伍」推断档案的运动项目，
  再按档案回填历史记录的项目快照；已有非空快照一律保留。
- 原 9 个项目名称一字不改，保证旧记录仍可评分：
  `30米冲刺、立定跳远、纵跳摸高、深蹲1RM、引体向上、12分钟跑、Yo-Yo间歇跑、体脂率、静息心率`。
- 程序读取表格时会自动给缺失的列补空，因此只有 7 列的旧备份 CSV 也能直接放进 `data` 使用。
- 内置约 31 个体能 / 描述项目 + 10 个 FMS 项目（7 动作 + 3 项排除性测试）。

### 运动项目与针对性口径

「运动项目」是大项，决定报告的关键能力域；「专项」是具体小项，只作档案记录。

| 运动项目 | 关键能力域 |
| --- | --- |
| 短跑 | 速度、爆发力、灵敏协调 |
| 中长跑 | 耐力、力量、身体成分 |
| 跳跃 | 爆发力、速度、柔韧 |
| 投掷 | 力量、爆发力、灵敏协调 |

> 预置 20+ 个大项，可在 `utils.py` 的 `SPORT_FOCUS` 中调整；选「其他」时按通用能力域处理。

### 分析报告生成流程

1. 在「05 分析报告」选择**队伍整体报告**或**个体运动员报告**，
   再选运动项目（个体模式默认取该运动员档案项目）、运动员、统计区间与是否纳入 FMS。
2. `reports.py` 按项目快照筛选记录，只用 `continuous` 已评分记录计算 0~100 分；
   FMS 的 0~3 分只用于风险、疼痛与不对称分析，不混入得分。
3. **不足项**：平均得分 < 60 分，或达标率 < 60%；命中该项目关键能力域、严重度高的排前面。
4. **原因分析**：最低能力域、关键能力域与整体的落差、逐项不足依据、最近两次趋势、
   队伍 / 同项目成员对比、FMS 风险与疼痛；每条都附可核对的数据依据。
5. **下一步改善建议**：P0 疼痛转介、P1 FMS 纠正、按能力域的训练与复测安排；
   按优先级排序，并列出训练周期与复测指标建议。
6. 报告可下载 Markdown（完整六章）与 CSV（不足项 / 改善建议 / 能力域汇总 / 明细数据）。

> 报告结论由内置规则基于已记录数据生成，不构成医疗诊断或训练处方；
> 常模为示意值，请按本队实测替换后再用于正式决策。

## 第 1 步：安装 Python（只需做一次）

### 1.1 先确认电脑是否已经装过

按 `Win + R`，输入 `powershell`，回车，打开一个蓝色的 PowerShell 窗口。输入：

```powershell
python --version
```

- 如果显示 `Python 3.11.x` / `Python 3.12.x` 之类的版本号 → **已装好，跳到第 2 步**。
- 如果显示 `Python was not found; run without arguments to install from the Microsoft Store` 或「无法将 python 项识别为…」→ **没装，继续 1.2**。
  本机目前就是这种情况，所以请按下面做。

### 1.2 下载安装包

1. 打开浏览器访问：<https://www.python.org/downloads/windows/>
2. 找到 **Stable Releases**，下载 **Windows installer (64-bit)**，推荐 Python **3.12.x**（不要选 3.14 这类最新的大版本，部分库还没适配）。
3. 下载得到一个文件，例如 `python-3.12.8-amd64.exe`。

> 如果官网打开很慢，可用国内镜像：<https://mirrors.huaweicloud.com/python/3.12.8/> ，选 `python-3.12.8-amd64.exe`。

### 1.3 安装（这一步有一个**必须勾选**的选项）

1. 双击下载好的 `.exe` 文件。
2. **在第一个界面最下方，务必勾选 `Add python.exe to PATH`**（把 Python 加入环境变量）。这是新手最容易漏掉、也最容易导致后面命令失败的一步。
3. 点击 **Install Now**，弹出「是否允许此应用更改设备」时点「是」。
4. 等待进度条走完，看到 **Setup was successful** 后点 Close。

### 1.4 验证是否成功

**关掉之前的 PowerShell 窗口，重新打开一个新的**（很重要，环境变量只对新窗口生效），输入：

```powershell
python --version
pip --version
```

看到类似下面这样，就成功了：

```
Python 3.12.8
pip 24.3.1 from C:\Users\...\python.exe (python 3.12)
```

> **如果仍提示找不到 python**：去「设置 → 应用 → 高级应用设置 → 应用执行别名」，把 `python.exe`、`python3.exe` 两个开关**关掉**，再重开 PowerShell 试一次。这个开关是 Windows 商店的占位程序，会挡住真正的 Python。

## 第 5 步：安装依赖库

先确认窗口前面有 `(.venv)`，再逐条执行：

```powershell
python -m pip install --upgrade pip
```

```powershell
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**这条命令在做什么**：`pip` 是 Python 的「装软件工具」，`-r requirements.txt` 表示按清单一次装好 3 个库（Streamlit 网页框架、pandas 数据处理、plotly 画图），`-i` 后面是清华镜像源，在国内下载更快。

**成功标志**：滚动一堆下载进度后，最后出现 `Successfully installed ...`，没有红色 ERROR。这个过程通常 1~5 分钟，请耐心等待，**不要关闭窗口**。

> 如果不加 `-i ...` 也能装，只是可能很慢或超时；超时就重新执行带镜像源的那条命令。

## 第 7 步：开始使用（建议先点这个按钮）

第一次打开是空的，首页会有一个 **「一键载入演示数据」** 按钮，点它，系统会自动生成覆盖
U16 / U18 / U20 / 成年 / 大师各年龄组的运动员、原 9 项体能记录、扩展项目、描述项
以及含疼痛与左右不对称情形的 FMS 筛查；每位运动员都有运动项目，每条记录都带项目快照，
所有图表和报告立刻就有内容了。

推荐顺序：

1. **运动员管理** → 新增运动员 2~3 人，**务必选择「运动项目」（必填）**；「适用标准组」会随性别和出生日期实时变化。
2. **评分标准** → 按本队实测替换示例常模；在「待配置清单」里把需要的组合补齐。
3. **测试与评估** → 「体能批量录入」一次填多个项目；再到「FMS 录入矩阵」做一次完整筛查。每条记录会自动关联建档时的运动项目。
4. **数据分析** → 在「体能分析」看 0~100 分趋势，在「FMS 分析」看 0~21 分风险与不对称清单。
5. **分析报告** → 切换「队伍整体报告 / 个体运动员报告」，按运动项目查看不足项、原因分析与改善建议，导出 Markdown 或 CSV。
6. **总览 / 个人成绩单** → 导出某位运动员的完整 CSV 成绩单。
7. 左侧菜单可以随时在 6 个页面间切换；改动会立刻存到 `data` 里的 CSV。

## 数据保存在哪里？怎么备份？

- 位置：`data` 文件夹里的 `athletes.csv`（运动员）、`tests.csv`（测试与评估）、`standards.csv`（评分标准）。
- 自动保护：**每次写入前**都会把旧文件复制到 `data\.snapshots\<时间戳>\`（保留最近 20 份）；
  写入走「同目录临时文件 → `os.replace` 原子替换」，断电或中断不会产生半行 CSV；
  同一时刻只允许 1 处写入（单写端锁，见 `docs\配置项说明.md`）。
- 整份备份：`utils.create_backup()` 会把 3 个 CSV + 清单写入 `backups\<时间戳>_<标签>\`；
  清空数据、恢复备份前系统也会自动各生成一份。也可以**直接复制整个 `data` 文件夹**到别处异地保存。
- 恢复：用 `utils.restore_backup(备份目录)`（会先校验 CSV 可读、再自动备份当前状态）；
  手工恢复则是把备份的 3 个 CSV 复制回 `data` 文件夹并刷新网页。
- 日志与审计：`logs\app.log` 记录异常堆栈，`logs\audit.log` 记录每次写操作；按大小轮转。
- 清空：首页 → 展开「数据管理」→ 勾选确认 → 点「清空全部数据」（评分标准配置会保留，清空前自动备份）。
- 「评分标准」页可以「恢复内置示例标准（270 行）」，用于把阈值还原到初始状态。
- 每个页面下方都有「下载 CSV」按钮，可导出到 Excel 做汇报；总览与「测试与评估」页可导出个人成绩单 CSV。
- 「05 分析报告」可导出完整的 Markdown 报告（六章），以及不足项、改善建议、能力域汇总、明细数据 4 类 CSV。

## 想稍微改一改？（可选，不影响运行）

**改评分标准**：不用改代码，直接在「评分标准」页选择性别和年龄组，编辑达标线 / 优秀线后保存。

**加测试项目**：在「评分标准」页的「自定义项目」里填写名称、单位、方向、类别与阈值，
系统会自动生成 10 行标准记录，并让新项目出现在录入下拉框中。

**改内置项目与示例常模**：用记事本或 VS Code 打开 `utils.py`：

- `CONTINUOUS_ITEMS`：27 个 0~100 分评分项的单位、方向、类别、达标线、优秀线。
- `DESCRIPTIVE_ITEMS`：仅记录不评分的描述项。
- `FMS_MOVEMENTS` / `FMS_CLEARING`：FMS 7 个动作、双侧标记与 3 项排除性测试。
- `AGE_FACTOR` / `GENDER_FACTOR`：示例常模按年龄组 / 性别的缩放系数。
- `AGE_GROUPS` / `age_group()`：年龄分档口径。
- `FMS_RISK_LINE`：FMS 风险线（默认 14 分）。
- `SPORT_FOCUS`：运动项目 → 关键能力域，决定报告的针对性口径；`EVENT_TO_SPORT`：旧档案迁移时的关键词推断表。
- `inject_css()`：界面配色（如 `#1e5b98`）。

**改分析报告规则**：打开 `reports.py`：

- `PASS_LINE`：不足项的得分达标线（默认 60 分）。
- `ADVICE_BY_CATEGORY` / `FMS_ADVICE` / `PAIN_ADVICE`：按能力域与风险给出的改善建议措辞。
- `_gaps()` / `_trend_findings()` / `_fms_findings()`：不足项、趋势与 FMS 的判定口径。

> 修改原 9 个项目名称会导致已有旧记录无法评分，**请勿改名**。

保存文件后，回到浏览器按 `F5` 刷新（或点页面右上角 `Rerun`）就能看到变化，不用重启命令。
