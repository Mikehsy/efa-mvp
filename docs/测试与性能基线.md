- 版本：`v1.0.0-dev`｜更新日期：2026-11-13
- 运行方式：`python -m unittest discover -s tests -t . -v`（或 `scripts\run_tests.ps1`）

## 2. 边界场景覆盖

| 类别 | 场景 | 结果 |
| --- | --- | --- |
| 数据状态 | 空数据、单条记录、仅档案、档案运动项目为空 | 6 页零异常，给出建档 / 恢复指引 |
| 数据文件 | 缺列、损坏、非 UTF-8、被占用 | 记录日志、页面提示恢复、按空表处理 |
| 数值 | 非数字、无穷大、FMS 0~3 越界、binary 文本 | `ValidationError` 或跳过评分 |
| 日期 | 非法字符串、未来日期、1950 年前、区间反转 | 明确中文提示 |
| 注入 | `= + - @` 公式前缀、前导控制字符、HTML 标签 | 写入前净化 / 显示层转义 |
| 并发 | 10 线程同时追加档案 | 单写端锁保证 10/10 落盘，无残留锁 |
| 报告 | 空筛选范围、无 FMS、无标准组、个体跨项目 | 不崩溃，给出数据不足说明 |
| 恢复 | 备份不完整、备份 CSV 不可读 | 取消恢复并给出原因 |

## 3. 性能基线（合成数据，单位 ms）

| 记录数 | `load_tests()` 优化前 | 优化后 | 报告生成优化后 | 内存 |
| --- | --- | --- | --- | --- |
| 582（演示数据） | 252.3 | **203.4** | 82.2 | 0.6 MB |
| 5,000 | 983.1 | **383.9** | 127.9 | 5.0 MB |
| 20,000 | 3,364.4 | **1,026.9** | 280.4 | 19.9 MB |

- 优化手段：`load_tests()` 的得分 / 等级 / 结果显示由逐行 `iterrows` + 216 行标准表布尔过滤，改为一次构建 `std_map` 后向量化；FMS 总分回填改为列表推导。
- **等价性验证**：优化前后 582 条记录的 `得分 / 等级 / 结果显示 / FMS总分 / 结果说明 / 不对称标记 / 运动项目 / 标准组 / 测试时年龄 / 评分类型 / 测试类别 / 单位` 共 12 列逐格一致，得分均值同为 `76.7467`。
- 验收口径（A6）：5000 条 `load_tests` P95 ≤ 1.5 s、报告 ≤ 1.0 s、首屏 ≤ 3 s —— **当前 384 ms / 128 ms，达标**。20000 条为压力参考档，非上线硬指标。
- 回归测试 `test_performance.py` 会把 582 条与 5000 条两档纳入每次运行。

## 5. 验证过程发现并已修复的问题

| 编号 | 现象 | 处理 |
| --- | --- | --- |
| V-01 | 向量化后空表 `pd.cut` 报 `Expected numeric dtype` | `load_tests()` 空表早返回并补齐派生列；显式声明 `float/bool` dtype |
| V-02 | 两个测试模块被 unittest 当作 `load_tests` 钩子调用 | 导入时改用别名 `load_test_records` |
| V-03 | 测试期望前导 `\t/\r` 被转义，实际由 `strip()` 清除 | 修正断言：控制字符剥离后已不构成注入 |
| V-04 | PowerShell 5.1 向 `python -c` 传中文按 GBK 编码，字面量比对失败 | 验证脚本改用列位置判断；部署脚本内不使用中文字符串 |
| V-05 | Streamlit 首页 HTTP 200 只是骨架页，不会执行脚本建表 | 部署验证改为显式调用 `ensure_files()` 模拟首次访问 |
