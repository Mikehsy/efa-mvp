## 一、取数前必须满足的三个条件（缺一不可）
1. **测法一致**：同一项目的常模只有在「测试协议、计时方式、场地、起跑方式、器材」一致时才可比较。例：30 米站立起跑 vs 行进间起跑，成绩差 0.3–0.6 秒；握力 Jamar vs 电子握力计数值不同。
2. **人群匹配**：NSCA/学术论文常模多来自大学生或特定项目运动员；直接套到"专业队 U16"或"游泳选手"会系统性误判。
3. **授权与引用**：NSCA 教材常模**受版权保护**（Human Kinetics 明确声明 excerpt 版权）。
   业务方 2026-11-18 决策：**不推进引用授权**，教材仅作内部方法学参考，不写入产品文案、不对外引用。
   系统实际写入的确认常模来自中国足协 / 协和 / 国家学生体质标准 / 临床规范（见 `docs/决策记录.md`），
   这些公开标准按《著作权法》不构成作品或属官方文件，内部引用需注明出处。

### L2 项目专项（必须由各国际单项联合会或队内历史提供）
> 你提到覆盖**全部夏奥/冬奥项目**。以下专项的能力模型与"达标线"差异极大，**L1 通用项无法替代**：
- **三大球**：FIFA/FIBA/FIVB 各自的体能测试框架（如 FIFA 的 Yo-Yo IR1、重复冲刺）
- **田径**：World Athletics 各单项成绩与年龄组标准（本身就有官方等级）
- **游泳**：World Aquatics 成绩标准 + 陆上力量/柔韧的专项常模
- **冰雪项目**：各国际单项联合会（FIS/ISU/IBU 等）的体能与测试结果，公开度较低，多依赖队内数据
- **建议**：为每个项目建立独立"项目常模子表"，而非强行塞进一张 270 行通用表。

### L3 梯队（U16/U18/U20/成年/大师）
- NSCA 常见分组是 14–15 / 16–18 / 大学 18–25，**"大师"组在体能常模中极稀少**。
- 梯队年龄折算须结合**发育阶段（PHV）**而非 purely 年龄；这属于训练科学决策，无法由通用表自动推出。
- **结论**：L3 必须使用队内实测数据校准，这是不可跳过的环节。
