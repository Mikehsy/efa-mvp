## 5. 异常处理要求

- 任一 P1 问题：立即登记，通知 DEV/运维，评估停用、回滚或切回上一版本。
- 任一 P2 问题：当日内给出责任人、预计处理时间。
- P3 问题：进入补丁窗口，不阻塞当日上线状态。
- 所有异常必须写入 `docs/观察期问题登记表.csv`。
