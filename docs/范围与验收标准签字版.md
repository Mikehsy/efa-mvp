## 1. 交付范围（In Scope）

1. **单机 / 局域网单实例**部署：≤5 人同时浏览、**≤1 人写入**；以物理单机、内网访问控制与操作审计替代账号权限。
2. 6 个页面全部功能：总览、运动员管理、测试与评估、数据分析、评分标准、分析报告。
3. 运动项目为档案必填字段；全部测试数据（含 FMS）通过写入时快照关联项目；旧 192 条记录前 7 列零差异。
4. 分析报告双模式（队伍整体 / 个体运动员）、按项目针对性生成，含不足项、原因分析、下一步改善建议，支持 Markdown 与 CSV 导出。
5. **真实常模替换**：27 项 × 2 性别 × 5 年龄组 = 270 组阈值，标记常模版本号与生效日期；替换后历史得分自动重算，口径需 BIZ 书面确认。
6. 数据可靠性：原子写入、写前快照、单写端文件锁、备份 / 恢复（脚本 + 入口）、输入校验补全。
7. 健壮性：全局异常兜底、结构化日志（保留 30 天）与操作审计、分级用户提示；生产配置关闭「一键载入演示数据」。
8. 工程化：锁定依赖版本、离线安装包、集中配置、启停 / 备份 / 回滚 / 探活脚本、固化回归测试。
9. 文档：《使用说明》《配置项说明》《部署与运维手册》《已知限制》《上线与回滚 SOP》+ CHANGELOG。
10. 上线与回滚演练、健康探活监控、问题反馈渠道与响应 SLA。

## 2. 明确不包含（Out of Scope，写入《已知限制》）

多用户账号 / 权限 / SSO、SQLite 或云数据库迁移、公网部署与等保合规、移动端适配、AI 生成建议、多语言、邮件推送、多人实时协同。以上列入 V1.1 评估，**不得在 V1.0 验收中作为缺失项提出**。

## 3. 验收标准（可量化，Go/No-Go 依据）

| 编号 | 维度 | 标准 | 验证方式 |
| --- | --- | --- | --- |
| A1 | 功能 | 6 页 × 4 种数据状态（空 / 仅档案 / 档案缺项 / 完整）零未捕获异常；核心流程用例 100% 通过 | `pytest` / `unittest` + `AppTest` |
| A2 | 报告 | 不足项、原因分析、改善建议三要素齐全；双模式均可生成并导出；关键能力域按项目匹配 | 报告引擎断言 + 人工抽检 |
| A3 | 数据 | 旧 192 条记录前 7 列零差异；582 条记录运动项目关联率 100%；演示数据可一键清空 | 迁移前后逐格比对 |
| A4 | 可靠性 | 写入中断 / 10 次并发写入后 CSV 可读、无半行；备份恢复演练 RPO ≤ 1 次写入、RTO ≤ 15 分钟 | 故障注入 + 演练记录 |
| A5 | 健壮性 | 12 类边界与异常场景均有明确中文提示、无白屏；日志可定位到页面 / 操作 / 对象 / 异常栈 | 边界用例 + 日志抽查 |
| A6 | 性能 | 基线 582 条：`load_tests` 242.1 ms、报告 75.1 ms；5000 条时 P95 ≤ 1.5 s / ≤ 1.0 s，首屏 ≤ 3 s；20 次并发只读无内存异常 | 三档数据压测 |
| A7 | 兼容性 | Python 3.11 / 3.12、Windows 10 / 11、Chrome / Edge 最近两版、离线 wheels 安装、UTF-8 CSV 用 Excel 正常打开 | 兼容矩阵 |
| A8 | 质量 | lint 0 错误、0 调试输出 / TODO、0 弃用 API 警告（现 42 处）、依赖可复现安装、评审问题清零 | 静态检查 + 评审清单 |
| A9 | 交付 | 5 份文档齐备、回滚演练成功、Go/No-Go 10 项全绿、BIZ 抽检 3 名运动员成绩单并签字 | 交付检查单 |

> A6 的性能目标在缺少 5000 条真实数据前以合成数据压测，结果标注「合成数据」；正式数据到位后复测一次。
