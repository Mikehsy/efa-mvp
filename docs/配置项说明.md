# 配置项说明

> 适用版本：`v1.0.0-dev`。所有路径与开关集中在 `config.py` 与 `.streamlit/config.toml`，无需改业务代码。

## 1. 环境变量（`config.py`）

部署时在 PowerShell 中设置，例如 `$env:EFA_ALLOW_DEMO_DATA = "0"`，再启动服务。

| 变量 | 默认值 | 作用 |
| --- | --- | --- |
| `EFA_DATA_DIR` | `<项目>\data` | 三个 CSV 与写前快照所在目录 |
| `EFA_BACKUP_DIR` | `<项目>\backups` | `create_backup()` / 脚本生成的整份备份 |
| `EFA_LOG_DIR` | `<项目>\logs` | `app.log` / `audit.log` 及轮转文件 |
| `EFA_ALLOW_DEMO_DATA` | `1`（允许） | 设为 `0` 后：空状态不再显示「一键载入演示数据」，`seed_demo_data()` 抛 `DataFileError` |
| `EFA_LOG_LEVEL` | `INFO` | 日志级别（`DEBUG` / `INFO` / `WARNING` / `ERROR`） |
| `EFA_LOG_MAX_BYTES` | `5242880` | 单个日志文件轮转阈值（字节） |
| `EFA_LOG_BACKUP_COUNT` | `10` | 轮转保留份数 |
| `EFA_LOCK_TIMEOUT` | `10` | 单写端锁等待超时（秒） |
| `EFA_STALE_LOCK_SECONDS` | `30` | 超过该秒数的残留锁文件自动清理 |
| `EFA_SNAPSHOT_KEEP` | `20` | 写前快照保留份数 |
| `EFA_BACKUP_KEEP` | `30` | 整份备份保留份数 |
| `EFA_STANDARDS_VERSION` | `示例常模 v0（待队内实测替换）` | 常模版本标记，显示在侧边栏，替换实测常模后应一并更新 |
| `EFA_ACCESS_PASSWORD` | （空） | 访问口令；**非空时启用统一登录闸口**（`utils.require_access_gate`），为空则完全不拦截，兼容演示/个人自用。商用建议设置强口令，并后续升级为多用户/角色认证 |

布尔值可用 `1/0`、`true/false`、`yes/no`、`on/off`。

## 2. Streamlit 配置（`.streamlit/config.toml`）

| 配置 | 值 | 说明 |
| --- | --- | --- |
| `server.headless` | `true` | 后台启动，不弹浏览器 |
| `server.port` | `8501` | 端口；被占用时可用 `--server.port 8502` 覆盖 |
| `server.address` | `localhost` | 仅本机；局域网改为 `0.0.0.0` 并配防火墙白名单 |
| `server.maxUploadSize` | `5` | 上传上限（MB） |
| `server.enableCORS` / `enableXsrfProtection` | `false` / `true` | 本地部署的安全边界 |
| `browser.gatherUsageStats` | `false` | 不向 Streamlit 发送使用统计 |
| `client.showErrorDetails` | `false` | 生产不暴露堆栈；完整堆栈在 `logs/app.log`。开发可临时改 `true` |
| `theme.*` | 蓝 / 白 / 浅蓝 | 与 `utils.inject_css()` 配色一致 |

## 3. 目录与文件

| 路径 | 内容 | 是否需备份 |
| --- | --- | --- |
| `data/athletes.csv` | 运动员档案（8 列，运动项目必填） | 是 |
| `data/tests.csv` | 测试与评估记录（14 列，含运动项目快照） | 是 |
| `data/standards.csv` | 评分标准（216 行） | 是 |
| `data/.snapshots/<时间戳>/` | 每次写入前的单文件快照，自动保留最近 20 份 | 可选 |
| `data/.write.lock` | 单写端锁文件，写入期间短暂存在 | 否（残留超过 30 秒会自动清理） |
| `backups/<时间戳>_<标签>/` | 三个 CSV 的整体备份 + `manifest.json` | 是（异地另存） |
| `logs/app.log` | 运行日志与异常堆栈（按大小轮转） | 否 |
| `logs/audit.log` | 写操作留痕：时间 / 操作 / 对象 / 结果 / 字段 | 建议保留 30 天 |

## 4. 数据可靠性约定（V1.0）

- **单写端**：同一时刻只允许 1 处写入；`data_lock()` 通过文件锁 + 进程内可重入计数保护整个「读-改-写」过程。
- **原子写**：先写同目录临时文件并 `fsync`，再 `os.replace` 替换；中断不会产生半行 CSV。
- **写前快照**：每次覆盖前把旧文件复制到 `data/.snapshots/`；清空数据、恢复备份前额外生成整份备份。
- **异常提示**：CSV 损坏 / 编码不符 / 被 Excel 占用时，`load_table()` 记录日志、在页面给出恢复指引，并按空表处理（此时请勿保存数据）。
- **备份恢复**：`utils.create_backup(label)` / `utils.list_backups()` / `utils.restore_backup(folder)`；恢复前会校验三个 CSV 可读并自动备份当前状态。

## 6. 回归测试运行方式

```powershell
cd "C:\Users\10692\CodeBuddy\20261113101802"
.\.venv\Scripts\Activate.ps1

# 离线环境（标准库，无需额外依赖）
python -m unittest discover -s tests -t . -v

# 联网安装开发依赖后也可
pip install -r requirements-dev.txt
pytest -q
```

`tests/__init__.py` 会把 `data / backups / logs` 全部指向临时目录并载入演示数据，**测试绝不会读写项目真实 `data`**；临时目录在进程退出时自动清理。
