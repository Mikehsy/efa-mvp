# 用户使用手册（面向教练 / 运动员管理员）

> 适用对象：日常录入、查看、导出评估数据的业务用户。技术部署见《部署与运维手册》，商用规划见《商用路线图与差距分析》。

## 1. 启动与访问
1. 在服务器/本机执行 `scripts\run.ps1`（首次或重启后）。
2. 浏览器打开 `http://localhost:8501`（局域网访问见运维手册，需 IT 放行 8501 并限 IP）。
3. 若已配置访问口令（`EFA_ACCESS_PASSWORD`），先输入口令进入。

## 2. 六大页面操作

### 🏅 主页（测试与评估总览）
- 一屏看：运动员数、测试记录数、平均体能得分、达标率、FMS 风险概览。
- 下方「全队体能得分趋势」「各项目平均得分」「FMS 概览区」。

### 👥 运动员管理
- **建档**：填运动员 ID（唯一）、姓名、性别、出生日期、所属队伍、专项、运动项目（必填），保存。
- **编辑 / 删除**：在表格里改完保存；删除需二次确认。
- 运动员 ID 是关联所有测试记录的钥匙，勿重复或随意改。

### 📏 测试与评估
- **单项录入**：选运动员、日期、项目、成绩、单位，自动按「评分标准」算得分/等级，写库即生效。
- **批量保存**：一次填多行后批量落盘。
- **FMS 录入矩阵**：一次性录入 7 个动作（0~3 分）+ 疼痛标记，自动汇总 FMS 总分与风险。
- **历史导出**：按筛选条件导出 CSV；可看单人成绩单。

### 📊 数据分析
- 体能分析：按运动员 / 项目 / 日期范围看进步曲线、最新得分对比、能力雷达、达标等级分布。
- FMS 分析：总分分布、各动作原始分、左右不对称清单、筛查明细。
- 所有图表与表格均可导出 CSV。

### ⚙️ 评分标准
- 按 性别 × 年龄组 编辑「达标线 / 优秀线 / 方向（越高越好或越低越好）」。
- 查看「待配置组合数」清零进度；可新增自定义项目；可一键「恢复内置示例标准」。
- **改完记得同步 `config.py` 的 `STANDARDS_VERSION` 并重启**，否则报告头部版本号不更新。

### 📝 分析报告
- 团队模式：按运动项目输出不足项（平均得分 < 达标线或达标率 < 60%）、原因分析、改善建议，可导出 CSV / Markdown。
- 个体模式：选中运动员生成个人报告，表格有边框/表头/斑马纹。

## 3. 数据安全与备份
- 所有数据在 `data/` 文件夹的 CSV（ athletes / tests / standards），可直接用 Excel 打开。
- 改数据前先复制整个 `data/` 文件夹备份；或用 `scripts\backup.ps1` 做带时间戳备份。
- 误删可用 `scripts\restore.ps1` 从备份恢复。

## 4. 常见问题
- **得分/达标率不对**：确认常模已替换且 `STANDARDS_VERSION` 已更新并重启（未替换前是示例口径）。
- **中文乱码**：CSV 必须 UTF-8（带 BOM 推荐）。
- **页面打不开**：服务是否在跑；`curl http://localhost:8501/_stcore/health` 应返回 `ok`。
