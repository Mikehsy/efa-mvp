# Demo 试用版部署指南（零服务器成本）

> 目标：不租云服务器，在你**自己的电脑**上跑系统，通过**内网穿透**生成一个公网网址发给客户，客户用平板/电脑浏览器打开即可试用。
> 成本：内网穿透免费版通常够用（0 元起）；只有你电脑开机时客户才能访问。
> 适用：产品推销、客户试用、收集反馈。正式商用走公有云 SaaS（Streamlit Cloud + Supabase），
> 按个人账号隔离；租户模型最终决策见 `docs/决策记录.md`（不做多队多租户）。

---

## 0. 整体原理（大白话）

```
客户浏览器 ──公网网址──> 内网穿透服务 ──转发──> 你的电脑(localhost:8501)
```
你电脑一直开着并运行系统，穿透工具给你一个 `https://xxx.cpolar.cn` 之类的网址，发给客户即可。

---

## 1. 你只需做一次：注册内网穿透账号

推荐 **cpolar**（国内、免费版够用、中文），备选 ngrok / natapp / 花生壳。

1. 打开 https://www.cpolar.com/ → 注册账号（免费）。
2. 下载 Windows 客户端并安装，用账号登录客户端（或复制官网给的 authtoken 配置一次）。
3. 完成后客户端会提示一个"隧道"配置。免费版给的是**随机二级域名**，每次重启可能变；如需固定域名可升级付费档。

> 这一步是**你需要本人完成的**（注册账号、下载安装），我无法代注册。

## 3. 每次演示的操作步骤

**第 1 步：启动系统**（在你电脑上，项目根目录执行）
```powershell
.\scripts\run_demo.ps1
```
看到 `Demo started ... Health check OK` 即成功。本机验证：`http://localhost:8501`，应出现登录页。

**第 2 步：启动内网穿透**（cpolar 客户端，或命令行）
```powershell
cpolar http 8501
```
终端会显示类似 `Forwarding  https://xxxx.cpolar.cn -> http://localhost:8501`。

**第 3 步：把 `https://xxxx.cpolar.cn` 发给客户**
- 客户在平板/电脑浏览器打开 → 看到登录页 → 用你给的账号登录 → 即可试用全部功能。
- 演示数据已内置（运动员、测试记录、评分标准），客户可直接看到图表和报告效果。

**第 4 步：演示结束**
- 关闭 cpolar（Ctrl+C）；系统可留着或执行 `.\scripts\stop.ps1` 停掉。

## 5. 注意事项与风险

- **电脑必须一直开机联网**，客户才能访问；关机/断网即不可用。
- **免费穿透域名可能变动**，发给客户前确认当前网址；需要固定网址可升级 cpolar 付费档（几十元/月），远低于云服务器。
- **演示数据与正式数据分离**：demo 用的是项目 `data/` 下的演示数据；切勿让客户录入真实运动员数据到 demo 环境（无隔离、无合规保护）。
- **公网暴露风险**：虽然加了登录页，但 demo 账号是公开的。演示结束及时关停隧道。
- 若客户反馈"打不开"：先确认你电脑上的系统和 cpolar 都在运行、网址是最新一次生成的。
